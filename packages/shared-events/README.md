# @tachi/shared-events

Paquete encargado de definir la infraestructura de eventos del dominio de Tachi.

## Responsabilidades

- Definir la interfaz de los eventos de dominio.
- Definir el contrato del Event Bus.
- Definir los handlers de eventos.
- Proveer implementaciones reutilizables del Event Bus.

## Dependencias

Este paquete no depende de Fastify, Supabase ni de ninguna infraestructura específica.
