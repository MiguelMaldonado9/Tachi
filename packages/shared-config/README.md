# @tachi/shared-config

Configuraciones compartidas utilizadas por todos los proyectos del monorepo Tachi.

## Contenido

- TypeScript
- ESLint
- Prettier
- Commitlint

## Objetivo

Centralizar la configuración para evitar duplicación y mantener consistencia entre:

- Backend
- Panel Administrativo
- Librerías compartidas
- Futuras aplicaciones
